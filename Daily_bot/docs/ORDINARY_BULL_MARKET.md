# 일반 상승장 근사 프로필

이 문서는 이전 `ordinary-bull` 프로필의 재현용 설명이다. 2026-11-28부터 CLI 기본값은 [korean](KOREAN_VOLATILITY_20261128.md)이며, 이 설정은 `--fake-profile ordinary-bull`로 선택한다. 기존의 큰 기울기와 넓은
호가 진동을 사용하는 모형은 `legacy`로 명시해 재현한다. 실거래 전략 설정은 바꾸지 않는다.

## 작동 방식과 구성

| 설정 | 값 | 의미 |
|---|---:|---|
| x | +7bp/일 | 기준가격의 평균 기울기 +0.07%/일 |
| n | 1.6bp | 기준가격의 틱 변칙 크기 |
| a, b | 1, 3 | 시간별 변칙 배율 |
| c, d | 0.1, 1 | 틱별 변칙 배율 |
| 기본 주문 수량 | 15주 | 합성 유동성의 수량 단위 |
| 표시 층 취소 확률 | 0.20/틱 | 해당 층 잔량의 일부 취소 |
| 공격 주문 배율 | 1.0 | 이전 모형의 4.0에서 축소 |
| 공격 주문 도착 확률 | 측별 0.5/틱 | 매 틱 양쪽에서 반드시 공격 주문을 내지 않음 |
| 공격 주문 최대 소진 | 1가격층/건 | 한 주문이 많은 가격층을 연달아 소진하는 상황 제한 |
| 기록·스캔 | 1초·60초 | 보유 관측과 신규 후보 평가 주기 구분 |

매수·매도 신규 지정가는 직전 체결가를 계속 따라 올리지 않고 각 참여자의 기준가격
주변에 제출한다. 기준가격이 내려가면 낮은 가격의 주문도 들어온다. 시장가와 시장성
지정가의 실제 체결은 기존 가격 우선·FIFO·부분 체결 규칙을 사용하며, 체결되지 않은
기준가격으로 현재가를 직접 바꾸지 않는다. 현재가는 마지막 실제 모의 체결가다.

기준가격 잡음과 주문 흐름의 난수는 분리한다. 기준가격 잡음의 시간 단위를 맞추기 위해
틱 변칙은 시간 간격의 제곱근으로 조정한다. 주문 도착·취소 과정은 여전히 틱 단위이므로
아래 검증은 하루 22,800틱, 09:00~15:20 연속 세션 기준이다. 틱 수 축소는 기능 점검용이며
같은 시장의 성긴 기록을 뜻하지 않는다.

10개 합성 종목은 매일 모두 모의 거래를 진행하고, 그중 선택한 5~10개만 CSV에 기록한다.
후보군에 빠진 날에도 가격은 움직이므로 다시 선택된 종목의 전일 종가는 마지막으로
기록된 날의 가격이 아니라 바로 전 모의 거래일의 종가다. 일별 전체 종가는 manifest에 남긴다.

## 실제 관측과 설계 가정

**관측 사실**과 **선택한 목표**를 구분한다.

- 한국은행의 2023년 연차보고서: 코스피 연간 상승률 18.7%.
- 한국은행의 2026년 9월 통화신용정책보고서: 2025년 코스피 일별 수익률 표준편차 1.4%.
  2026년 1~7월의 4.1%는 위기급 변동성으로, 이번 일반 상승장 목표로 쓰지 않았다.
- 저장소의 실제 market_traces 16개 파일, 유효 호가 117,657행: 스프레드 중앙값1틱,
  95백분위3틱, 현재가와 중간호가의 차이 중앙값0.5틱·95백분위1.5틱.
  10행마다 추출한 최우선 잔량 중앙값은 매수91주·매도80주였다.
- **설계 선택**: +0.07%/일은 252거래일 단순 복리 환산 약 +19.3%, 66일 약 +4.7%의
  기울기다. 실제 경로가 이 수익률을 달성하도록 강제하지 않는다.
- **설계 선택**: n=1.6의 틱 변칙만으로 하루 기준가격 잡음 표준편차는 이론상 약 1.47%다.
  이는 종목별 기준가격 변동의 목표이며 지수와 개별 종목의 변동성이 동일하다는 뜻이 아니다.

자료의 근거:

- [한국은행 2023년 연차보고서](https://www.bok.or.kr/portal/bbs/P0000596/view.do?menuNo=200071&nttId=10083282)
- [한국은행 2026년 9월 통화신용정책보고서](https://www.bok.or.kr/portal/bbs/B0000156/view.do?menuNo=200754&nttId=11064613)
- 저장소 `Daily_bot/logs/market_traces_2026*.csv`의 호가 관측. 종목 선정 편향과 2026년의
  특수한 시장 상황을 포함한다. 완전한 1초 체결 테이프나 일반적인 상승장 표본은 아니다.

## 검증 범위

16개 시드 × 4가격대(1,500·7,500·25,000·150,000원), 종목·일 64개에서 각각 22,800틱을
실행했다. 같은 시드의 가격대별 기준가격 경로는 같으므로 독립 경로는 16개다.

| 항목 | 일반 상승장 프로필 검증값 |
|---|---:|
| 종목·일 수익률 표준편차 | 1.234% |
| 상승 마감 비중 | 53.125% |
| 각 사례 스프레드 중앙값의 중앙값 | 1틱 |
| 각 사례 최우선 잔량 중앙값의 중앙값 | 105주 |
| 각 사례 현재가-중간호가 차이 중앙값의 중앙값 | 0.5틱 |

실제 호가의 중앙 수준에 맞춘 근사 설정이다. 꼬리 분포는 더 좁으며, 급격한 유동성 고갈,
뉴스 갭, VI·거래정지, 종목 간 상관관계, 개장·마감 단일가, 휴장일은 보정하지 않았다.
가격 흐름과 호가 통계를 점검한 것이며 전략의 수익률로 파라미터를 선택하지 않았다.
상승일을 강제하지 않으며, 짧은 표본에서 평균 수익률이 음수가 나오는 것도 허용한다.

이전 모형의 큰 호가 간격과 호가 보충 편향 때문에 과거 합성 백테스트 결과는 이 프로필의
결과와 모델 버전을 구분해 해석해야 한다. 실거래 수익성을 입증하는 자료는 아니다.

## 사용법

자료만 생성:

```bash
python -m Daily_bot.backtest.fake_market --fake-profile ordinary-bull --fake-days 1 --fake-stocks 5 --fake-output-dir ./ordinary-bull
```

바로 백테스트:

```bash
python -m Daily_bot.backtest.replay_refill_threshold --market-source fake --fake-profile ordinary-bull --fake-days 1 --fake-stocks 5 --fake-no-viewer --starting-capital-krw 1000000 --refill-min-expected-return 0.90
```

명시한 `--fake-x`, `--fake-n` 등은 프리셋 값을 덮어쓴다. 이전 모형 재현에는
`--fake-profile legacy`를 사용한다. Python의 `MarketConfig()` 자체 기본값은 기존 데이터
재생성 스크립트와의 호환성을 위해 legacy이며, `ordinary_bull_config()`가 새 설정을 반환한다.
