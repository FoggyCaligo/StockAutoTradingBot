# 종가 단일가·VI 적용 6개월 백테스트

## 구현 범위

기존 한국장 변동성 보정(n=4.292969240786431), 시드 20261128, 0001년
1~6월 평일 130일과 종목별 기준가격 경로를 유지하고, 종가 단일가와 VI를 켰다.
과거 월별 ZIP은 그대로 보존하고 새 자료로 별도 replay한다.

KRX 일반주식 규칙을 참고했다.

- 접속매매의 동적 VI: 일반 종목 6%, KOSPI200 옵션 3%.
- 종가 단일가의 동적 VI: 일반 종목 4%, KOSPI200 옵션 2%.
- 정적 VI: 직전 단일가 체결가 대비 10%. 시가 단일가는 생략해 최초 참조가는
  가정한 개장 기준가(전일 종가)다. 단일가 체결 이후 참조가를 갱신한다.
- 체결 예정 가격을 **체결 전에** 검사한다. 발동 주문 잔량부터 모아 2분 동안
  체결을 멈춘다. 0~30초 임의 종료를 독립 시드로 뽑고 10초 기록 격자에 올림한다.
- 15:20 이후에는 주문을 모아 15:30 이후 한 가격으로 체결한다.
  종가 단일가 중 VI가 발동하면 2분 단일가 기간을 보장하도록 종료를 연장한다.
  VI 단일가 중에는 VI를 중복 발동하지 않는다.
- 단일가 가격은 최대 체결 수량 → 최소 잔량 불균형 → 직전 체결가와 가까운 가격
  순으로 고른다. 같은 가격의 주문은 FIFO, 유리한 가격과 시장가부터 배분한다.
  직전가 근접/마지막 낮은 가격 선택은 거래소의 모든 동률 규칙을 복원하지 않은 근사다.
- 합성 시장가의 미체결 잔량은 단일가 체결 뒤 취소한다. VI 해제 때 합치 가격이
  없으면 재접수 기간을 연장하고, 장 종료 때 합치 가격이 없으면 마지막 체결가를 보존한다.

참고:
[KRX VI 기준](https://global.krx.co.kr/contents/GLB/06/0602/0602010204/GLB0602010204T9.jsp),
[KRX 단일가 체결](https://regulation.krx.co.kr/contents/RGL/03/03010201/RGL03010201.jsp),
[KRX VI 해제 시각 유의사항](https://data.krx.co.kr/contents/MDC/STAT/issue/MDCSTAT224.jsp).

개장 단일가, 파생 만기일의 별도 1% VI, CB·거래정지, 신규상장 예외,
특수 수량배분은 구현하지 않았다. 15:20 경계와 겹친 VI는 종가 단일가에
합치는 근사이며, 개별 호가 수신 시각과 거래소의 모든 세부 우선순위까지 재구성하지 않는다. FAKE 종목은 일반 종목 기준으로 실행했다.

## replay 처리

단일가 접수 중 표시 호가가 교차하는 것은 체결 가능 상태가 아니다.
표준 replay와 보수적 체결기는 접수 중 신규 진입/체결을 허용하지 않는다.
대기 중에도 기존 동적 손절·강제청산 조건은 평가한다. 발동된 청산 의도는
보관하고, 거래가 재개된 뒤 체결한다. VI를 이유로 손절 기준을 바꾸지 않는다.
기존 보유 주문은 단일가 체결 시 실제 합치 가격에서 판정하고, 새 진입이 이미
끝난 단일가 체결에 소급 참여하지 않도록 해당 프레임의 신규 진입을 막는다.
보수적 체결기는 단일가 체결량의 참여율 한도도 공유해 중복 체결시키지 않는다.

현재 설정의 강제청산은 15:15로 종가 단일가 이전이다. 종가 단일가가 당일
수익에 직접 영향을 거의 주지 않을 수 있으며, 전일 종가 연결과 VI가 영향을 준다.

## 비교 방법

- 표준: 현재가 전량 매수, 후속 가격 도달 청산의 기존 표준 runner.
- 보수적 참고: 지연 1초, 호가 참여율 10%, 대기열 배율 1, 매수 대기 30초.
  10초 자료에 맞춰 체결 테이프 허용 간격은 15초로 지정한다.
- 최초 진입 0.71%, 익절 반환 슬롯 0.90%, 가중치 하한 0.0, 신규 진입
  09:30~11:30, 동적 기대수익률 -0.1% 3회 손절과 슬롯 폐쇄 정책을 유지한다.
- 매일 고정 100만원 자본, 복리 아님. 무거래일을 포함한 130일 평균을 계산한다.
- 비용: 매수/매도 각각 0.015% 수수료, 2026년 일반주식 매도 총세율 0.20%.
  기존 코드의 0.18% 가정도 별도로 보존한다. 표준 체결기의 거래 선택·현금 갱신은
  비용과 독립이므로 체결 원장에 새 세율을 정확히 재계산한다. 보수적 체결기는
  비용이 현금에 반영되므로 0.20%로 실제 다시 실행한다.
  [2026년 세율 안내](https://securities.koreainvestment.com/main/customer/guide/_static/TF04ae010000.jsp?tab=3),
  [시행령 개정 이유](https://www.law.go.kr/lsRvsRsnListP.do?lsId=005028).
  기록 날짜 0001년은 합성 식별자이며 세율을 고대 연도로 추정하지 않는다.
- 새 daily adapter는 CSV를 하루씩 읽어 기존 `replay_refill_threshold.main()`에
  전달한다. 거래 규칙을 다시 구현하지 않으며, 동일 CSV의 SQLite importer와
  행 전체가 같다는 회귀 검사를 통과해야 한다.
- 평가 함수의 큰 객체 복사를 값 복사로 바꿔 처리 시간을 줄였다. 고정 난수
  10,000개 호가에서 기존 예측과 일치하고 입력이 변하지 않는지 확인했다.
- 미적용 자료와 적용 자료는 같은 기준 경로/시드를 쓰지만, 주문장 피드백과
  난수 소비 순서가 달라져 이후 주문 흐름도 달라진다. 손익 차이를 단일 제도의
  순수 인과효과라고 해석하지 않는다.

## 재현 명령

```bash
python -m Daily_bot.backtest.regenerate_korean_mixed --auction-vi --output ./auction_mixed
python -m Daily_bot.backtest.validate_korean_mixed --input ./auction_mixed --output ./auction_mixed/validation.json
python -m Daily_bot.backtest.replay_synthetic_archives --input ./auction_mixed --output ./auction_replay
python -m Daily_bot.backtest.replay_synthetic_archives --input ./auction_mixed --output ./conservative_replay --fill-model conservative
```

`--wait`는 월별 생성이 끝난 순서로 처리한다. `--resume`은 동일 입력·설정으로
중단된 실행만 재개하는 옵션이다. 다른 설정 결과를 같은 폴더에 섞지 않는다.
