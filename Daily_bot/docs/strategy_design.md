# Daily Bot Strategy Design

이 문서는 **현재 전략의 의도와 설계 철학**을 설명한다. 정확한 활성값은 `CURRENT_DAILY_SETTINGS.md`, 세부 실행 흐름은 `DAILY_BOT_LOGIC_REFERENCE.md`, 최종 진실원천은 `settings.yaml`과 실코드다.

## 1. 전략의 핵심 아이디어

현재 Daily Bot은 차트 패턴을 길게 해석하는 전략이 아니라, **20호가 잔량이 가리키는 매우 단기적인 균형가격과 현재가의 차이**를 거래한다.

핵심 가정은 다음과 같다.

- 현재가 부근의 호가잔량은 가까운 미래 가격에 더 직접적인 영향을 준다.
- 현재가에서 멀리 떨어진 잔량은 실제 체결 압력으로 이어질 가능성이 낮으므로 덜 믿어야 한다.
- 호가에서 계산된 예상가가 현재가보다 충분히 높을 때만 진입하면 작은 가격 차이를 반복적으로 수익화할 수 있다.

## 2. 호가 모델

매수/매도 양쪽 20호가를 사용한다.

- 가까운 호가 가중치: `1.0`
- 먼 호가 가중치: `0.0`
- 중간 호가: 거리순 선형 감쇠

즉 **중간값/현재가에서 멀수록 호가잔량의 가중치를 줄인다.**

이 가중치를 적용한 뒤 매수·매도 잔량을 상쇄해 단기 균형가격 `expect_price`를 계산한다. 목표 매도가는 예상가에서 1틱을 낮춘 가격을 기본으로 한다.

## 3. 유니버스

전략은 KOSPI와 KOSDAQ 전체를 넓게 보되, 지나치게 작은/얇은 종목은 제외한다.

현재 기본 조건:

- KOSPI + KOSDAQ
- 시가총액 2,500억 원 이상
- 거래대금 30억 원 이상
- 추세 필터 OFF

현재 전략은 업종이나 장기 차트 방향을 직접 강제하지 않고, **당시 호가 구조와 유동성**을 더 우선한다.

## 4. 최초 진입과 재진입을 다르게 본다

현재 전략에서 중요한 설계 포인트다.

### 최초/미사용 슬롯

아직 그날 사용되지 않은 자본 슬롯은 기대수익률 `0.71%` 이상이면 진입할 수 있다.

### 익절로 반환된 슬롯

이미 한 번 거래에 사용되어 익절로 돌아온 슬롯은 더 엄격하게 본다. 기대수익률 `0.90%` 이상이어야 재진입한다.

이 구분은 단순 보수화가 아니라 백테스트에서 `0.71%` 자유 재진입보다 `0.90%` 재진입이 더 나은 결과를 보였기 때문에 채택됐다.

## 5. 슬롯은 자본에 따라 변한다

현재 전략은 “항상 3종목”이 아니다.

- 최소 3슬롯
- 주문가능 자본 500만 원 단위로 슬롯 증가 가능
- 최대 10슬롯
- 총 보유 하드 상한 10종목
- 한 스캔에서 신규매수는 최대 3종목

따라서 자본이 커져도 한 번에 진입 속도를 과도하게 늘리지 않으면서 총 운용 슬롯은 확장할 수 있다.

## 6. 익절 슬롯은 다시 쓴다

현재는 full-batch lock을 사용하지 않는다.

즉 전체 슬롯이 한 번 채워졌더라도 익절로 빈자리가 생기면 11:30 전까지 다시 매수할 수 있다. 단 재진입 문턱은 `0.90%`다.

설계 의도는 다음 두 가지의 절충이다.

- 좋은 장에서는 익절된 자본을 다시 회전시켜 수익 기회를 놓치지 않는다.
- 재진입 품질 기준을 높여 단순 회전율 증가로 인한 비용/저품질 거래를 줄인다.

## 7. 손절은 가격 고정선보다 “예상가 붕괴”를 본다

현재 고정 퍼센트/틱 손절은 꺼져 있다.

대신 보유 중에도 20호가를 다시 읽어 예상가를 재계산한다.

기본 dynamic stop:

```text
expected_return <= -0.1%
3회 연속
```

즉 매수가 대비 몇 % 떨어졌는지만 보는 것이 아니라, **현재 호가 구조상 앞으로 기대되는 가격 자체가 더 이상 수익을 지지하지 않는지**를 본다.

Dynamic stop이 발생하면:

- 해당 종목 청산
- 같은 날 해당 종목 재진입 금지
- 해당 슬롯은 그 거래일 동안 폐쇄
- 다음 거래일에는 슬롯 복구

## 8. 시간 제한

신규 진입은 `09:30 ~ 11:30`만 허용한다.

12:30까지 연장하는 실험에서는 거래 수는 늘었지만 전체 순이익과 MDD가 모두 악화되어 현재는 11:30을 유지한다.

남은 포지션은 15:15에 강제청산한다. 전략이 오버나이트 포지션으로 변질되지 않도록 하기 위한 경계다.

## 9. 현재 의도적으로 꺼둔 필터

다음 필터는 현재 핵심 전략에 포함하지 않는다.

- top-ratio 랭킹 컷 (`1.0`)
- fallback 진입
- 스프레드 상한
- 전일 등락률 필터
- 직전 스캔 급등 필터
- 매도호가 깊이 제한
- 추세 필터
- 고정 퍼센트/틱 손절

현재 방향은 “안전장치를 많이 겹치는 전략”보다 **호가 기대수익률 신호 자체의 품질을 검증하는 전략**에 가깝다.

## 10. 전략의 현재 성격

현재 전략은 다음 균형을 지향한다.

- 최초 진입은 충분히 넓게 허용한다.
- 익절 재진입은 조금 더 엄격하게 한다.
- 기대가 무너지면 dynamic stop으로 빠져나온다.
- 손절이 발생한 슬롯은 당일 추가 위험을 늘리지 않는다.
- 하지만 익절 슬롯까지 막는 full-batch lock은 사용하지 않는다.

즉 **안정성만 극대화하는 전략이 아니라, 수익 기회를 유지하면서 실패한 슬롯만 당일 축소하는 구조**다.
