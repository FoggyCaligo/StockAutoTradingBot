# 한국 주식 관측 기반 변동성 보정과 6개월 교체 자료

2026-11-28부터 가상 생성 CLI의 기본 프로필을 `korean`으로 교체했다.
실거래 설정, 최초 진입 0.71%, 반환 슬롯 재진입 0.90%는 변경하지 않았다.
가상 CSV/DB는 소스 저장소에 넣지 않고 월별 ZIP으로 분리한다.

## 변동성을 정한 근거

`calibrate_volatility.py`는 기록된 현재가의 1·5·15분 로그수익률을 계산한다.
같은 종목/날짜/호가 시각은 중복 제거하고, 각 기간 이상의 간격으로 앵커를 띄운다.
앞으로 해당 기간이 지난 첫 관측만 사용하며 허용 오차는 기간의 20%다.
실제 경과 시간으로 표준화한 수익률 양끝 1%를 winsorize한 표준편차를 사용한다.
시가총액 지수나 종가 등락률을 장중 분 단위 변동성으로 대신 쓰지 않는다.

- 훈련: 2026-09-03·09-04의 2,745행. 중복 호가 시각 522개.
- 보류 검증: 2026-11-23의 2,770행. 이 날짜로 계수를 맞추지 않았다.
- 기존 잡음 `sign × U(0.1,1)`의 2차 모멘트는 0.37이다.
  각 기간 SD를 `sqrt(기간 초 × 0.37)`로 나누고, 세 기간의 중앙값을 취했다.
- 결과: **n=4.292969240786431**, 이전 n=1.6의 **2.6831배**.
- 출처별 체크섬과 표본 수는 `backtest/calibration/korean_volatility_20261128.json`에 있다.

| 구간 | 훈련 표준편차 | 훈련 관측/종목일 | 보류 표준편차 | 보류 관측/종목일 |
|---|---:|---:|---:|---:|
| 1분 | 0.2202% | 192 / 5 | 0.2612% | 333 / 4 |
| 5분 | 0.4349% | 283 / 234 | 0.4347% | 426 / 346 |
| 15분 | 0.7834% | 16 / 2 | 0.9983% | 28 / 4 |

봇이 관찰한 선택 종목의 표본이다. 특히 1·15분의 종목 범위가 좁아서
한국 시장 전체를 대표한다고 볼 수 없다. 15분 추정의 표본 수도 작다.
주문 도착률·취소율·잔량 충격 지속성까지 실증 추정했다는 뜻은 아니다.

## 새로운 기본값

`--fake-profile korean`이 기본이며 가격 경로 잡음을 높이는 동시에 이전에 보정한
가격대 표본과 독립적인 잔량 분산을 기본 적용한다. 기록은 10종목, 09:00~15:30
양 끝 포함 10초 간격(종목당 2,341개), 후보 평가는 60초다.
동일 관측 주기를 고정해야 동적 손절 연속 3회의 의미도 비교할 수 있다.
`ordinary-bull`, `legacy`는 명시적으로 선택해 이전 자료를 재현할 수 있다.

KRX 일반주식 호가단위를 live/replay와 공유하며 전일 기준 ±30% 범위에서만
주문한다. 현재가는 체결로만 바뀌고 가격/시간 우선, FIFO, 부분체결을 유지한다.
거래시간과 가격 제한의 참고 기준은
[KRX 거래 안내](https://global.krx.co.kr/contents/GLB/01/0109/0109000000/guide_to_trading_in_the_korean_stock_market.pdf),
[KRX 호가단위](https://regulation.krx.co.kr/contents/RGL/03/03010100/RGL03010100T3.jsp)다.
15:20~15:30은 연속매매로 근사한다. 시가·종가 단일가, VI, 거래정지, 공휴일은 구현하지 않았다.

## 0001년 6개월 시나리오

고정 시드 20261128, 0001-01-01~0001-06-30의 평일 130일이다.
앞 65일은 약한 상승장, 뒤 65일은 강한 하락장이다.
10초 간격 전체 3,043,300행을 월별 ZIP으로 저장한다.
거래 수나 수익을 보고 시드·임계값을 고르지 않는다.

- 상승 기준: 일 기울기 +0.03%, 분기 기준가격 약 +1.97%, 변동성 배율 1.0.
- 하락 기준: 일 기울기 -0.6%, 분기 기준가격 약 -32.37%, 변동성 배율 1.5.
  하락장 배율 1.5는 스트레스 가정이며 관측 자료에서 추정한 값이 아니다.
- 기준 경로는 Gaussian 확산에 분기 끝점을 조건으로 한 Brownian bridge를 쓴다.
  기존 signed-uniform 잡음과 초당 분산을 맞추고, 공통 충격 비중 0.35와
  독립 충격을 합친 뒤 등가중 시장 기준에 정규화한다. 이는 시나리오 가정이다.
- 분기 기준가격 끝점은 각 종목에도 조건화된다. 실제 한국 종목의 분기 수익률
  횡단면을 재현하는 모형은 아니다. 이 고정 경로를 실제 시장 예측에 쓰지 않는다.
- 주문장의 실제 종가를 다음 날 전일 종가와 가격 제한에 전달한다.
  기준 경로는 연속되지만 체결가와 기준가격 차이로 작은 시가 갭이 남을 수 있다.
- 봇 주문은 생성 주문장에 들어가지 않는다. 봇 replay의 대기열/시장충격과
  실제 승률·수익률을 검증한 자료가 아니다.

## 고정 첫날 비교

같은 시드·가격대·잔량·시간·시나리오에서 n만 1.6 / 4.292969240786431로 바꾼
1일 10종목 비교다. 표의 값은 기준가격이 아닌 **실제 모의 체결가**에서 계산했다.

| 구간 | n=1.6 | 새 n | 훈련 관측 |
|---|---:|---:|---:|
| 1분 SD | 0.1194% | 0.1799% | 0.2202% |
| 5분 SD | 0.1900% | 0.4193% | 0.4349% |
| 15분 SD | 0.2750% | 0.6971% | 0.7834% |

계수 2.68배가 모든 실현 변동성을 2.68배 만든다는 뜻은 아니다. 호가단위,
체결 지연과 주문 잔량 때문에 단기 실현 변동성은 다르다. 첫날 진입창의
0.71% 이상·1주 예산 가능 스캔은 9개였고, 표준 replay는 1거래를 만들었다.
이는 입력 연결 확인용이며 6개월 성과가 아니다.

## 재현

저장소 루트에서 실행한다. 출력 디렉터리는 비어 있어야 한다.

```bash
python -m Daily_bot.backtest.calibrate_volatility \
  --training Daily_bot/logs/market_traces_20260903.csv Daily_bot/logs/market_traces_20260904.csv \
  --holdout Daily_bot/logs/market_traces_20261123.csv \
  --output Daily_bot/backtest/calibration/korean_volatility_20261128.json

python -m Daily_bot.backtest.regenerate_korean_mixed --output ./korean_mixed_0001
python -m Daily_bot.backtest.validate_korean_mixed \
  --input ./korean_mixed_0001 --output ./korean_mixed_validation.json

# 단일 세션 기본 생성 / 격리된 표준 replay
python -m Daily_bot.backtest.fake_market --fake-output-dir ./korean_one_day --fake-no-viewer
python -m Daily_bot.backtest.replay_refill_threshold --market-source fake \
  --fake-output-dir ./korean_one_day_replay --fake-no-viewer \
  --starting-capital-krw 1000000 --refill-min-expected-return 0.90
```

월별 ZIP 안의 `fake_market_traces_*.csv`를 새 폴더에 푼 뒤 기존 가상 CSV
패턴을 명시하여 replay DB를 만든다. 압축파일을 실거래 로그 폴더에 섞지 않는다.
`manifest.json`에는 날짜별 CSV 체크섬·행 수·전일 종가·종가가,
`scenario.json`에는 조건과 월별 ZIP 체크섬이 포함된다.
